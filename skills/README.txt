技能目录说明
============

这里放 *.md 文件，格式与 DSH 桌面版的 SKILL.md 一致：

    ---
    name: 技能名称
    description: 一句话说明什么时候该用它
    when: 触发词，写，润色，polish，改写
    default: auto
    ---
    正文：写给模型的指令……

frontmatter 字段
----------------
  name        必填，列表里显示的名称。
  description 建议填，列表 title 与缺省描述用它。
  when        可选，触发词，用逗号 / 中文逗号 / 顿号 / 竖线分隔，最多 24 个。
  default     可选：on=常驻、auto=按需、off=默认关闭。
              写了 when 却没写 default 时视为 auto；都没写视为 on（老技能行为）。

三种模式（2.4.1）
----------------
  常驻 always 每轮对话都注入系统提示词。2.4.0 及更早的技能默认就是这个。
  按需 auto   只有用户本轮消息（含最近几条用户消息）命中 when 才注入，
              单轮最多 3 个，按命中词数排序。技能多也不会撑爆免费模型上下文。
  关闭 off    不注入。

网页左侧「技能」面板点击可循环切换：关闭 → 常驻 → 按需 → 关闭。
只有写了 when 的技能才有「按需」这一态。圆点：绿色=常驻，琥珀=按需，灰=关闭。

其他约定
--------
- 启用技能的正文会追加到系统提示词，请控制篇幅（单文件建议 < 3000 字，正文最多取 6000 字）。
- 文件名即技能 ID（不含 .md），只允许字母、数字、连字符。
- 删除文件即可移除技能；新增文件刷新页面后自动出现，无需重启。
- 解析 frontmatter 用显式 \r?\n 而非 \R —— 字节模式下 \R 会把 UTF-8 续字节
  0x85（如「清」）当换行，切出半个汉字导致整段 JSON 编码失败。
- 自检：php -c php-local.ini tools/check-skills.php（tools/ 不上传）。

## 输出顺序

1. **结构**：先说页面分区与信息层级，再谈视觉。
2. **设计令牌**：给一段可直接粘贴的 `:root` CSS 变量块（背景 / 面板 / 边框 / 文本 / 强调色 / 圆角 / 阴影）。
3. **关键 CSS**：只给真正影响观感的规则，不复制整份样式表。

## 约束

- 明暗主题由用户指定；未指定用浅底 + 中性灰 + 单一强调色。**中国区金融/行情场景涨用红、跌用绿**。
- 正文与背景对比度至少 4.5:1；避免大面积纯黑配纯白。
- 移动端优先：断点 820px / 480px，可点击区域 ≥44px，输入框字号 ≥16px 防缩放。
- 字体用系统栈 `system-ui, -apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`，不依赖外部字体。
- 动效 ≤200ms，并提供 `prefers-reduced-motion` 降级。
- 半透明面板要同时考虑 `backdrop-filter` 不可用时仍可读的兜底底色。

## 说明方式

- 给具体数值（颜色值、间距、圆角），不要只说「再柔和一点」。
- 涉及改动时明确写出「选择器 → 原值 → 建议值」，便于直接落地。

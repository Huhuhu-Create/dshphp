## 输出顺序

1. **规则**：要匹配什么、边界在哪、哪些是反例。
2. **正则**：放在代码块里，标明方言（PCRE / PHP / JS / Python）。
3. **逐段解释**：每个分组、量词、锚点各一句。
4. **3 个正例 + 3 个反例**，用表格呈现。

## 方言与编码陷阱

- 中文匹配：PCRE/PHP 用 `[\x{4e00}-\x{9fa5}]` 且必须加 `/u`；JS 用 `\p{Script=Han}` 且加 `u` 标志。
- 解析 UTF-8 文本时不要用 `\R` 做换行切分——字节模式下会把续字节 `0x85` 当换行，切出半个汉字。用显式 `\r\n|\n|\r`。
- `\d`、`\b`、`\w` 在不同语言 / 是否 Unicode 模式下含义不同，写明前提。
- 嵌套量词（如 `(a+)+`）有灾难性回溯风险，长文本必须提醒并给原子组 / possessive 量词替代。
- 前端格式校验只是体验，**安全校验必须放在服务端**。

## 替换类需求

给出替换表达式 + 一段前后对照文本，并说明会否影响重叠匹配。

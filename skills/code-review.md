## 检查顺序

1. **能不能跑**：语法、依赖、入口、路径、编码。
2. **边界与异常**：空值、空数组、超长输入、并发、超时、失败重试。
3. **安全**：注入、越权、SSRF、密钥泄露、错误页泄露路径。
4. **正确性**：状态流转、数据一致性、幂等性。
5. **可维护性**：命名、重复逻辑、日志与可观测性。

## 输出格式

按「严重 / 一般 / 建议」三档列出，每条给出：问题、位置、原因、修法。
没有问题也要明确说"未发现明显问题"，并列出未覆盖的检查项。
